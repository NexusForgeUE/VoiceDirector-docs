VoiceDirector 使用指南

让剧本成为游戏中的声音

适用于 Unreal Engine 5.5-5.8 的 VoiceDirector 分步指南。导入台词，录制或生成配音，挑选满意的版本，再发布为游戏可播放的音频资源。

按钮和字段保留插件界面中的英文名称，操作说明使用中文。

1

VoiceDirector 能做什么

#

VoiceDirector 是 Unreal 编辑器中的对话制作工具。你提供台词，选择声音或导入录音，试听后决定哪一版用于游戏。最终产物是 Unreal 标准音频资源 SoundWave。设置对话绑定后，也可以创建 DialogueWave。

选项卡用途
Lines导入剧本、选择台词、试听和批准录音。
Voices为每个角色和语言分配服务商声音。
Jobs查看生成进度，打开新录音。
Publish检查并应用游戏音频资源的变更。
Settings配置连接、输出、DataTable 映射和限制。

台词是剧本中的一条记录；语言变体是这条台词的某种语言版本；录音版本（take）是该变体的一次录制或生成。可以保留多个版本，同时继续使用游戏中原来的音频。

可以直接从现有 WAV 开始，AI 生成不是必需步骤。VoiceDirector 不编写台词、不翻译文本、不克隆声音，也不在游戏运行时生成语音。

2

安装并打开插件

#

第一次创建 Unreal 项目

  1. 打开 Epic Games Launcher > Unreal Engine > Library，启动 UE 5.5、5.6、5.7 或 5.8。
  2. 在项目浏览器中选择 Games > Third Person，再选 Blueprint 和 Desktop。Blueprint（蓝图）是通过连接节点编写的可视化程序，本指南无需编写 C++。
  3. 填写项目名称，选择有空余空间的文件夹，点击 Create，等待编辑器加载。

添加 VoiceDirector

使用与你的 Unreal 版本匹配的 Windows x64 插件构建。通过 Fab 安装时，在 Launcher 库中将插件添加到对应引擎版本。安装到项目时，先关闭编辑器，再把完整插件文件夹放到 YourProject/Plugins/VoiceDirector/。没有 Plugins 就新建它。

YourProject/Plugins/VoiceDirector/VoiceDirector.uplugin

不要再嵌套一层 VoiceDirector。纯蓝图项目需要已编译的包及随附的构建文件。只有源代码的包需要 C++ 编译器并自行构建。

  1. 重新打开项目，进入 Edit > Plugins，搜索 VoiceDirector 并启用。
  2. 按提示重启编辑器。
  3. 打开 Tools > VoiceDirector。

只安装一份：放在引擎中或项目中。重复安装可能导致项目无法打开。

3

完成第一句可播放台词

#

本教程使用随附录音，无需先配置 Kokoro 或 ElevenLabs。

可下载的示例

第一句台词已准备好导入

包含一行 CSV 和真实 WAV，内容为 “Keep your voice down.”。示例由本地 Kokoro 生成。导入时无需服务器或账号。

下载 CSV下载 WAV
  1. 打开 Settings，把 Output Content folder (/Game/...) 设为 /Game/VoiceDirector/Audio，点击 Save Output Folder。/Game 指项目的 Content 目录，不是 Windows 磁盘。
  2. 将两个示例文件下载到容易找到的文件夹。
  3. 在 Lines > Import script 中，把 Import SourceId 设为 MyScript，点击 Import CSV 并选择示例 CSV。
  4. 检查预览，点击 Apply Import。本教程不要勾选 Full snapshot。
  5. 选中 L-001 的 en 变体。点击 Import WAV，选择示例录音。
  6. 必要时点击 Select take，再点 Play。你会听到 “Keep your voice down.”。Stop 停止试听。
  7. 点击 Approve take 批准录音。
  8. 进入 Publish，或点击 Review publishing。点击 Refresh Preview，勾选新 SoundWave 的行，再点 Apply Selected Approved。
  9. 用 Ctrl + Space 打开 Content Drawer，进入 Content > VoiceDirector > Audio。接着学习在游戏中播放。

窗口较窄时，用 Sources & filters 打开导入区域，用 Take review 打开录音审核，也可双击台词。资源名出现 VD_... 属于正常情况；Copy 可复制完整路径。

4

编写并导入剧本

#

在电子表格或文本编辑器中编写台词，导出为逗号分隔的 UTF-8 CSV。

LineId,CharacterId,Culture,Text,Context
L-001,rowan,en,Keep your voice down.,At the city gate
列名含义
LineId稳定的台词 ID。修改文字时保留此 ID。
CharacterId稳定的角色 ID，用于关联声音分配。
Culture语言代码，例如 en、fr、ru。
Text显示的台词文本，必填。
Context可选的场景或表演提示。
SpokenText可选的实际朗读文本；为空时使用 Text。
SourceNamespace / SourceKey / SourceRevision可选的来源元数据。

进入 Lines > Import script，填写稳定的 Import SourceId，点击 Import CSV。检查 Added / Changed / Archived / Unchanged，再点 Apply Import。仅查看预览不会修改台词。

重新导入时使用相同的 SourceId 和 LineId，可保留标识和历史录音。同一来源中 LineId/Culture 必须唯一。一个 LineId 可以有多个语言版本，角色应保持一致。

Full snapshot 会将本来源、此次涉及语言中未出现的台词归档。仅在完整替换这一范围时启用。不启用则保留缺失行。归档不会删除录音。

含逗号的单元格用双引号包围，内部引号写两次："他说 ""等等。"""。表格软件通常会自动处理。分号分隔的文件需要重新导出为逗号分隔。限制：16 MiB、10,000 行。

5

导入 Unreal DataTable

#

DataTable 是 Unreal 内的表格资源。直接选择它，无需手写 JSON 或另存 CSV。

  1. 在 Settings > Script DataTable 中选择资源。
  2. 将列映射到 LineId、CharacterId、Culture、Text，以及可选的 Context、SpokenText。支持 String、Name、Text。@RowName 可把行名作为 LineId。
  3. 来源自动根据 DataTable 资源路径确定。点击 Preview DataTable Import。
  4. 在 Lines 检查变更，点击 Apply Import。

从零创建表格

在 Content Browser 中创建 Blueprint Structure，加入 String 字段 LineId、CharacterId、Culture 和 Text 字段 Text、Context、SpokenText。保存后创建 Data Table，选择该结构作为行类型，添加行并填写示例值。最多 10,000 行。

插件也提供编辑器导入行类型 VoiceDirectorScriptRow。打包游戏本身需要的表格应使用你自己的运行时结构。发布后的 SoundWave 是普通游戏资源。

6

为角色选择声音

#

声音来自 Kokoro 或 ElevenLabs 的现有目录。分配将声音绑定到 CharacterId + Culture，并不会创建新声音模型。

  1. 按后续章节配置服务商。
  2. 在 Voices 选择服务商，点击 Check Connection / List Voices。这只读取目录，不生成语音。
  3. 填写剧本里的 CharacterId 和 Culture，选择 Voice、Model，调整可用参数，点击 Save Voice Assignment。
  4. 回到 Lines，选择一个变体，点击 Generate new take。

示例：rowan、en、Kokoro 声音 af_heart、模型 kokoro。声音必须支持目标语言。导入 WAV 无需声音分配。更改分配只影响后续生成，旧录音保留原始设置。

7

配置本地 Kokoro

#

Kokoro-FastAPI 独立运行在本机或可访问的服务器上。VoiceDirector 不安装或启动它。为依赖和模型预留磁盘空间。

  1. 按照 Kokoro-FastAPI v0.9.0 官方安装说明操作。Windows CPU 方式需要安装前置组件、下载模型，再在后端目录运行 .start-cpu.ps1。
  2. 等待服务及模型加载。本地默认安装可在浏览器打开 http://127.0.0.1:8880/docs 检查连接。
  3. 在 Settings 把 Kokoro-FastAPI base URL 设为 http://127.0.0.1:8880/v1，点击 Save Settings。
  4. 在 Voices 加载目录。可先使用 af_heart、kokoro、英语 en、速度 1.0。

Kokoro 速度范围为 0.5-2.0。支持语言取决于模型和声音。可以导入俄语文本与 WAV，但此 Kokoro 集成不生成俄语语音，需要其他合适来源。

生成时保持服务运行。已发布的游戏音频不依赖服务继续运行。

8

配置 ElevenLabs

#

需要你自己的 ElevenLabs 账号、额度和具有权限的密钥。生成消耗账号额度，大批量生成前请查看当前价格。

  1. 在账号中打开 Developers > API Keys。创建密钥，启用 Voices: Read 和 Text to Speech: Access。若限制模型访问，允许所需模型。
  2. 在 Windows 开始菜单搜索编辑账户的环境变量。在用户变量中点击新建，名称填 VOICEDIRECTOR_ELEVENLABS_KEY，值填密钥，确认各窗口。
  3. 完全退出 Unreal 和 Epic Games Launcher，包括系统托盘进程，再重新启动，使其继承变量。
  4. 在 Voices 选择 ElevenLabs，点击 Check Connection / List Voices，选择账号可用的声音和模型。
  5. 保存分配，先生成一句短台词并试听。

密钥只放在环境变量中。Settings 没有密钥输入框。不要把密钥放入剧本、资源、截图或支持邮件。

插件请求 pcm_24000 并将 PCM 响应封装成 WAV。能读取目录不代表账号具有此格式的生成权限。速度范围 0.7-1.2；风格和 speaker boost 仅在模型支持时可用。

现有密钥可通过 More Actions (...) > Edit 修改，参见官方密钥指南。权限、额度或区域访问错误应先向服务商解决，再重试。

9

生成并查看任务队列

#
  1. 在 Lines 选择变体，用 Ctrl 或 Shift 多选。
  2. 单个变体点击 Generate new take，多个点击 Generate selected。确认前检查服务商、请求数、字符数和费用估算。
  3. 在 Jobs 查看进度。Pause 暂停新请求，Resume 继续，Cancel 停止剩余队列。
  4. Completed 后点击 Open take，会在 Lines 打开对应录音并清除隐藏它的筛选。

完成的录音仍需试听、批准和发布。错误诊断可以复制。每批最多 1,000 个变体，每次 TTS 请求最多 5,000 字符。

UnknownRemoteOutcome 表示请求已发出，服务端可能已完成，但结果未收到。再次生成前先检查服务商历史。取消不会撤回已发送请求。

10

试听并挑选录音版本

#

审核面板显示录音文本、来源、时间、时长和由真实 WAV 计算的波形。切换台词即可查看该台词的历史。

状态含义
Selected当前审核的录音，不改变游戏音频。
Approved该变体已批准的表演。
In game / 已发布目前写入游戏资源的录音，直到应用下一次发布。
Current / Stale / Unknown是否匹配当前已知输入。修改文本或声音可能使旧录音过期。
Human / AI导入 WAV 或服务商生成。导入的 WAV 也可能是在其他工具中生成的。

使用 Select take、Play、Stop，满意后点击 Approve take。所有版本仍可比较。波形显示按可读性缩放，比较音量请实际聆听。

导入自己的录音

选择一个变体，点击 Import WAV。要求 little-endian RIFF WAV，16 位 PCM、24 或 48 kHz、单声道或立体声，最大 64 MiB。MP3、浮点 WAV 和 24 位 PCM 必须先转换。

More line actions 提供锁定、翻译审核、保留稳定 ID 的重命名和对话绑定。替换批准版本前先解锁。相同输入再次生成时，勾选 Create another take even if input matches。

11

发布游戏音频资源

#

只有发布才会更改游戏使用的资源。导入、生成和批准本身保留原音频。

  1. 打开 Publish > Refresh Preview。
  2. 检查路径与操作：Create 创建、Update 更新、Conflict 需要处理。
  3. 勾选目标已批准行及所需的基础 SoundWave 或对话依赖。
  4. 点击 Apply Selected Approved 并查看结果。Copy 复制路径。

外部修改、未保存或只读资源不会被直接覆盖。解决冲突后刷新预览。发布过期但已批准的版本需要明确启用 stale takes 选项；先对比录音和文字。

已批准版本和游戏中的版本可以不同。Publish 明确应用这次切换。

12

在游戏中播放台词

#
  1. 打开关卡，在主工具栏选择 Blueprints > Open Level Blueprint。
  2. 找到 Event BeginPlay，没有时右键图表并搜索添加。
  3. 从白色执行引脚拖出连线，搜索并创建 Play Sound 2D。
  4. 在 Sound 字段选择发布后的 SoundWave。
  5. 点击 Compile，保存蓝图和关卡，回到编辑器点击 Play。

台词将在关卡开始时播放。空间中的角色语音可使用 Unreal 位置音频节点和自己的对话逻辑。在游戏中引用资源，使其包含在打包内容中。

运行时播放无需编辑器模块、密钥或 TTS 服务。参见 Epic 的 Play Sound 2D 文档。

13

语言版本与对话上下文

#

翻译行保留 LineId、CharacterId，修改 Culture：例如 L-001,rowan,en 和 L-001,rowan,fr。翻译、对应声音和录音由你提供。

默认源语言是 en。基础 SoundWave 与新的本地化版本一起发布。本地化资源使用 Unreal 的 /Game/L10N/<culture>/... 结构。游戏引用基础资源，由当前活动文化选择本地化。

在 Project Settings > Packaging 包含所需文化和国际化数据。只修改编辑器界面语言不会配置游戏对话语言。

DialogueWave

创建说话者和可选听者的 DialogueVoice 资源。在 More line actions 中选择 Dialogue speaker、听者和稳定的 Context key，再点 Save Dialogue Context。将必需的 SoundWave、DialogueWave 一起发布。

DialogueVoice 是对话元数据，不是声音模型。每个 LineId 对应一个上下文；其他上下文使用不同台词 ID。

14

收集配音演员的录音

#
  1. 准备剧本，点击 Settings > Export Actor Manifest CSV。
  2. 将清单发给演员，保留 ID 和规定的 WAV 文件名，并要求支持的录音格式。
  3. 用 Choose Actor Manifest 选择原始清单，用 Choose Returned WAV Folder 选择返回的录音目录。
  4. 点击 Preview Actor Matching，检查就绪、缺失和歧义匹配，先修正文件。
  5. 选中就绪行，点击 Import Selected Actor WAVs，然后试听、批准并发布。

录音保留原清单的台词。如果录制期间剧本发生变化，录音可能被标记为过期；请比较实际说出的内容。

15

设置与生成限制

#

Settings 包含 Kokoro URL、输出、DataTable、演员工具和队列限制。Save Settings 保存连接及生成设置，Save Output Folder 保存输出目录。

可以限制请求和字符数量。美元估算需手动填写每 1,000 字符价格。价格 -1 表示未知；美元预算 -1 表示无金额上限。启用金额上限但价格未知时，云生成会被阻止，直到可以估算。

估算基于你填写的价格，不是账号余额，也不保证最终扣费。还需考虑服务商额度。

这些是本地编辑器偏好设置，正常操作不需要编辑 JSON。

16

备份与恢复工作

#

备份整个项目，包括：

目录内容
Content/已发布资源和源 DataTable。
VoiceDirector/剧本、录音历史和保存的源 WAV。
Saved/VoiceDirector/本地设置、任务及发布日志、恢复备份。

一个 SoundWave 无法恢复全部历史。同一项目只能由一个编辑器写入。只读实例恢复写入时，关闭另一编辑器并重启当前编辑器。不要删除仍由进程使用的写锁。

中断生成后查看 Jobs。结果未知的已发送请求不会自动重试；先查看服务商历史。

在 Publish 中使用检测到的 Review interrupted publication，或点击 Restore From Publish Journal，选择本项目 Saved/VoiceDirector/Publish/<batch>/Journal.json。阅读确认提示。恢复解决前保留日志和备份。外部修改会产生冲突，新建资源也可能留在磁盘供检查。需要帮助时保留项目副本并联系支持。

排查问题

#
现象检查项目
找不到插件Edit > Plugins 启用并重启，检查 Tools、匹配 UE 构建和单份安装。
按钮不可用正确选择台词或录音；检查锁定、只读、导入或活动队列。发布需要批准。
CSV 导入失败UTF-8、逗号、准确列名、非空 ID、唯一 LineId/Culture，阅读诊断。
Kokoro 目录为空服务运行、/docs 可达、保存的 URL 以 /v1 结尾，再刷新目录。
ElevenLabs 拒绝重启后继承变量、Voices: Read、Text to Speech: Access、模型/格式权限、额度和 API 访问。
HTTP 429按服务商提示等待、缩小批次、手动重试，避免连续快速发送。
没有波形或声音源 WAV 存在且 PCM 格式支持，输出设备和音量正确；缺失文件从备份恢复。
结果未知再次生成前检查服务商请求历史。
Conflict阅读完整诊断和路径；处理外部修改、未保存或只读，再刷新。
游戏无声执行引脚连接、Sound 正确、编译保存完成、音量可听、资源及文化包含在构建中。
18

常见问题

#
第一课需要付费吗？

导入 CSV/WAV 和播放资源不需要服务商账号。ElevenLabs 使用其价格和额度。本地 Kokoro 需要安装服务及下载模型。

台词和声音来自哪里？

你提供文本。音频来自你的 WAV 或服务商。VoiceDirector 管理录音，不编写故事也不训练声音。

需要 C++ 或手写 JSON 吗？

编译好的插件可用于纯蓝图项目。声音、设置和 DataTable 使用界面操作。自行编译源码是另一种开发流程。

新录音会立即替换游戏声音吗？

不会。先试听、批准，再明确应用发布。在此之前继续使用上次发布的录音。

切换文档语言会保留当前位置吗？

会保留当前章节。插件按钮仍使用原来的英文名称，方便查找。

打包游戏能生成新语音吗？

VoiceDirector 1.0.0 是编辑器制作工具。游戏播放已发布的标准资源，不提供运行时 TTS。
